# 🥗 Счетчик калорий и программа для похудения

Настольное приложение на **Python + Tkinter** для учёта калорий, контроля
рациона и отслеживания прогресса похудения. Все данные хранятся локально в
JSON-файле — без интернета и без внешних баз данных.

-----

## 📖 Описание приложения

«Счетчик калорий и программа для похудения» — это персональный дневник
питания и веса. Приложение помогает:

- завести профиль пользователя и рассчитать ключевые показатели здоровья;
- вести ежедневный дневник питания по приёмам пищи;
- следить за суммарной калорийностью и БЖУ за день;
- отслеживать динамику веса и прогресс к целевому весу;
- хранить и просматривать историю по дням;
- экспортировать данные в CSV и JSON.

Интерфейс построен на вкладках (`ttk.Notebook`) с современным оформлением,
адаптивной компоновкой и приятной зелёной «здоровой» цветовой схемой.

-----

## ✨ Возможности

**Учёт пользователя**

- Имя
- Возраст
- Пол
- Рост (см)
- Текущий вес (кг)
- Целевой вес (кг)
- Уровень физической активности

**Автоматический расчёт**

- Индекс массы тела (ИМТ / BMI) и его интерпретация по классификации ВОЗ
- Базовый обмен веществ (BMR) по формуле Миффлина–Сан Жеора
- Суточная норма калорий (TDEE) с учётом активности
- Рекомендуемый дефицит калорий для безопасного похудения
- Целевая калорийность с защитным минимумом 1200 ккал

**Дневник питания** (для любой даты)

- Приёмы пищи: завтрак, обед, ужин, перекусы
- Встроенная база продуктов (значения на 100 г): по выбранному продукту и весу
  порции калории, белки, жиры и углеводы считаются **автоматически**
- Любой новый продукт, добавленный вручную, сохраняется в базу — в следующий раз
  расчёт по нему тоже будет автоматическим
- Для каждого продукта: название, вес в граммах, калории, белки, жиры, углеводы
- Подсчёт калорий, белков, жиров и углеводов за день
- Запись веса за конкретный день
- Добавление и удаление продуктов

**Прогресс похудения**

- Текущий вес
- Целевой вес
- Сколько осталось сбросить
- Прогресс-бар выполнения цели в процентах
- График изменения веса (на базе **matplotlib**) с линией целевого веса

**История**

- Таблица по дням: вес, калории, БЖУ
- Двойной клик по дню открывает его в дневнике питания

**Экспорт данных**

- Экспорт всех данных в **JSON**
- Подробный отчёт по приёмам пищи в **CSV** (совместим с Excel, кодировка UTF-8-SIG)

**Хранение данных**

- Все данные — в локальном файле `data.json`
- Файл создаётся автоматически при первом запуске
- При повреждении файла приложение восстанавливает корректную структуру

## 🛠 Установка

Требуется **Python 3.8+**. Модуль `tkinter` входит в стандартную поставку
Python (на некоторых дистрибутивах Linux устанавливается отдельно:
`sudo apt install python3-tk`).

Установите единственную внешнюю зависимость:

```bash
pip install matplotlib
```

-----

## ▶️ Запуск

```bash
python main.py
```

При первом запуске рядом с программой автоматически создастся файл `data.json`.
